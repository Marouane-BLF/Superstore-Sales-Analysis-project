# Raw Dataset

Store the original source dataset used by the Super Store Sales & Delivery Analytics report in this folder.

## Handling Rules

- Preserve the original file without cleaning or overwriting it.
- Record the original filename, source URL, download date, and license or usage terms when known.
- Note the file format and approximate row count after checking the source.
- Do not commit private, confidential, or restricted data.
