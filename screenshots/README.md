# Dashboard Screenshots

This folder is intended to contain image previews of the three Power BI report pages. Use PNG or JPG images that are readable at repository preview size.

## Recommended Files

| Filename | Report page |
|---|---|
| `sales-performance.png` | Sales Performance Dashboard |
| `delivery-performance.png` | Delivery Performance Dashboard |
| `category-segment-analysis.png` | Category & Segment Analysis |

The root `README.md` references these filenames to display the previews. Keep the filenames in sync with the actual image files committed to this folder.

## Before Publishing

- Check that chart labels and KPI cards remain legible.
- Remove any confidential information.
- Make sure screenshots reflect the current version of the report.
- Avoid presenting a KPI as a verified business conclusion until its calculation has been checked in the Power BI model.
