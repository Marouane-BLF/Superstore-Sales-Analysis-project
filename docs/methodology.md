# Methodology

## Workflow
1. Record the original data source and preserve the raw dataset.
2. Inspect data types, missing values, duplicates, date fields, and relevant business definitions.
3. Perform and document data preparation in Power Query.
4. Build or verify the data model and measures used by the report.
5. Validate KPI calculations and check totals against the source data.
6. Build visuals that answer the business questions in the root README.

## Transformations
Document only the steps actually applied. Include assumptions and any known limitations.

Add each KPI's formula, numerator/denominator where relevant, date logic, and business interpretation after verifying the Power BI model.
