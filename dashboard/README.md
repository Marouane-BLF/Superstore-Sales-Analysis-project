# Power BI Report

Place the `.pbix` report file in this folder.

## Open the report
1. Download the `.pbix` file and open it in Power BI Desktop.
2. If prompted, update the data source path to the dataset in `../data/cleaned/` or your local copy.
3. Refresh the data and verify the DAX measures and KPI definitions.

Document the report page names, KPIs, and any known data-source requirements once confirmed from the actual report.
